## Principles I Work By

- **Context before patterns:** A fashionable pattern is not automatically the right design.
- **Operability is part of architecture:** Observability, failure modes and recovery belong in the design from the beginning.
- **Guardrails should enable teams:** Effective governance improves decision quality without stalling delivery.
- **Modernisation needs boundaries:** Service decomposition succeeds when ownership, data and operational boundaries are clear.
- **AI confidence is not AI correctness:** Fluent output still requires evidence, grounding and human accountability.
